# MS 274 Project
Files for  MS 274 Project.

Project Title: 
The effects of El Nino Conditions on juvenile shiner surfperch

Project Description:
This project will combine longterm surf zone monitoring data with 2026 field collections to capture juvenile shiner surfperch size in relation to environmental conditions at Stillwater Cove. A strong El Nino event began developing in 2026, and is predicted to peak in late 2026 and persist through early 2027. While the California coast is typically highly productive, El Nino can reduce primary productivity in the coastal ocean (Chavez et al., 2002). In addition, El Nino can depress the thermocline, resulting in warmer surface temperatures. While reductions in primary productivity could alter prey availability for juvenile surfperch, warming temperatures may lead to faster developmental times and larger initial size at age (Fisher et al., 2015; Lomartire et al., 2021; Lindmark et al., 2022).
